# Крестики-нолики

[English](README.md) | **Русский**

Десктопная игра «Крестики-нолики» на Python с использованием [customtkinter](https://github.com/TomSchimansky/CustomTkinter). Можно играть с другом на одном компьютере или против встроенного ИИ. Вы сами выбираете, кто ходит первым и кто играет крестиками или ноликами.

## Возможности

- Три режима: игрок против игрока, игрок против ИИ, ИИ против игрока
- Выбор того, кто ходит первым
- Выбор символа первого игрока: **X** или **O**
- Таблица результатов за сессию: победы игрока 1, победы игрока 2, сыгранные партии и ничьи
- Визуальный результат партии: поле становится зелёным при победе и чёрным при ничьей
- Всплывающее сообщение с итогом каждой партии
- Простой чёрно-белый интерфейс на customtkinter
- Новую партию можно начать в любой момент одной кнопкой, счёт сохраняется

## Режимы игры

| Игрок 1 | Игрок 2 | Режим |
|---------|---------|-------|
| Человек | Человек | Двое людей за одним компьютером |
| Человек | ИИ      | Вы игрок 1, ИИ игрок 2 |
| ИИ      | Человек | ИИ игрок 1, вы игрок 2 |

Настройки в верхней части окна можно свободно комбинировать:

- **Who goes first?**: кто ходит первым, игрок 1 или игрок 2
- **Who will be player 1?**: человек или ИИ
- **Who will be player 2?**: человек или ИИ
- **Символ игрока 1**: X или O

Например, если ИИ это игрок 1 и он ходит первым, то он делает ход сразу после нажатия **play**, а вы играете противоположным символом.

## Как работает ИИ

ИИ работает по набору правил. На каждом ходу он проверяет приоритеты сверху вниз и делает первый подходящий ход:

1. **Победа**: если у него две отметки в ряд и третья клетка свободна, он занимает её
2. **Блокировка**: если у соперника две отметки в ряд, он занимает третью клетку
3. **Центр**: занимает центральную клетку, если она свободна
4. **Угол**: занимает случайный свободный угол
5. **Сторона**: занимает случайную свободную боковую клетку

ИИ всегда побеждает или блокирует, если может, но не просчитывает ходы вперёд, поэтому его можно обыграть, создав двойную угрозу. Углы и стороны выбираются случайно, так что партии каждый раз разные.

## Установка

Требования:

- Python 3.8 или новее
- [customtkinter](https://pypi.org/project/customtkinter/)

```bash
git clone https://github.com/<your-username>/<your-repo>.git
cd <your-repo>
pip install customtkinter
```

`tkinter` входит в стандартный установщик Python на Windows и macOS. В некоторых дистрибутивах Linux его нужно поставить отдельно:

```bash
sudo apt install python3-tk
```

## Запуск

Убедитесь, что файл `imag.ico` лежит в одной папке со скриптом, затем выполните:

```bash
python main.py
```

Пошагово:

1. Выберите, кто ходит первым.
2. Выберите, кто игрок 1 и кто игрок 2 (человек или ИИ).
3. Выберите, чем играет игрок 1: X или O.
4. Нажмите **play**.
5. Кликайте по свободным клеткам, чтобы делать ходы.
6. Когда партия закончится, снова нажмите **play**, чтобы начать новую. Счёт сохранится.

## Сборка в .exe

Игру можно превратить в отдельное приложение для Windows с помощью [PyInstaller](https://pyinstaller.org/):

```bash
pip install pyinstaller
pyinstaller --onefile --windowed --icon=imag.ico --add-data "imag.ico;." main.py
```

Готовый файл появится в папке `dist`. Чтобы иконка корректно загружалась внутри собранного `.exe`, загружайте её через функцию `openicon`:

```python
window.wm_iconbitmap(openicon("imag.ico"))
```

На Linux и macOS в `--add-data` вместо `;` используйте `:`.

## Структура проекта

```
.
├── main.py          # логика игры, ИИ и интерфейс
├── imag.ico         # иконка окна
├── screenshot.png   # скриншот для README
├── README.md        # английская версия
└── README.ru.md     # русская версия
```

Основные части `main.py`:

- `Cs()`: логика хода ИИ
- `Win()`: проверяет победу или ничью, обновляет счёт и цвета поля
- `GameOver()`: показывает, закончена ли текущая партия
- `step()`: обрабатывает клик по клетке
- `StartGame()`: считывает настройки, очищает поле и начинает новую партию
- `openicon()`: определяет путь к ресурсам, в том числе при запуске из сборки PyInstaller

## Известные ограничения

- Режим ИИ против ИИ не поддерживается
- Иконка `.ico` работает на Windows, на Linux и macOS её может понадобиться убрать или заменить
- Счёт не сохраняется после закрытия программы
- ИИ можно обыграть
